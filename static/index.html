About

The Ledger is a local dashboard for AI usage. The Swear Meter idea is credited to petergpt/codex-swear-meter.

It reads local records, counts matching user messages, and shows totals without showing raw messages.

How the Swear Meter works

  1. Scan user messages from local Codex records.
  2. Match the word sets below.
  3. Count one message once for the index, even when it hits more than one set.
  4. Count every matched phrase for hits.
